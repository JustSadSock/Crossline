# Crossline (offline)

Браузерная арена против бота. Никаких серверов и туннелей: всё работает локально в одном окне.

## Что внутри

- `/index.html`, `/scripts`, `/styles` — лобби, офлайн‑игра и интерфейс.
- `package.json` — только вспомогательные npm‑скрипты, без зависимостей.

## Как запустить

1. Откройте `index.html` в браузере (двойной клик или через локальный веб‑сервер).
2. Выберите сложность, укажите ник и нажмите «Играть офлайн».
3. Если нужно вернуться в лобби, используйте кнопку «В лобби».

## Скрипты npm

- `npm run test` — заглушка, потому что серверный код удалён и автоматических проверок нет.

## Минимальный стек

- Современный браузер с поддержкой ES-модулей и Canvas.
